## SÊNIOR — SÊNIOR Arquitetura Front-end

**18. Frontend Engineering Avançado** *(próprio)*
- 18.1 Arquitetar aplicações frontend complexas com boundaries, feature modules, state machines e contratos de domínio
- 18.2 Implementar padrões avançados de gerenciamento de estado, cache server-state, sincronização e concorrência de UI
- 18.3 Projetar estratégias de SSR, SSG, ISR, streaming, hydration seletiva e renderização híbrida
- 18.4 Estruturar testes em pirâmide frontend com unitários, integração, contrato, E2E, acessibilidade e visuais
- 18.5 Integrar micro-frontends, module federation, monorepos e estratégias de compartilhamento de dependências
- 18.6 Definir padrões técnicos para escalabilidade, manutenção, observabilidade e evolução arquitetural contínua

**19. Web Platform & Browser Avançado** *(próprio)*
- 19.1 Diagnosticar gargalos avançados de renderização com tracing, flame charts, main thread analysis e long tasks
- 19.2 Projetar estratégias de execução eficiente com Web Workers, OffscreenCanvas, scheduler APIs e task splitting
- 19.3 Implementar arquiteturas offline-first com Service Workers, cache versionado, background sync e fallback resiliente
- 19.4 Aplicar segurança avançada no navegador com CSP, Trusted Types, COOP, COEP, CORP e mitigação de XSS
- 19.5 Otimizar carregamento com resource hints, streaming, priority hints, HTTP/2, HTTP/3 e cache partitioning
- 19.6 Integrar Web APIs avançadas como Web Components, Web Streams, WebAssembly, Broadcast Channel e Performance API

**20. CSS & Layout Systems Avançado** *(próprio)*
- 20.1 Criar sistemas de layout escaláveis com CSS Grid avançado, subgrid, container queries e cascade layers
- 20.2 Implementar arquitetura CSS com design tokens, custom properties, logical properties e theming dinâmico
- 20.3 Resolver problemas complexos de stacking context, containment, scroll behavior, overflow e composição visual
- 20.4 Construir interfaces responsivas fluidas com clamp, minmax, aspect-ratio, intrinsic sizing e layout adaptativo
- 20.5 Otimizar CSS para performance com critical CSS, pruning, redução de recalculation e isolamento de escopo
- 20.6 Projetar padrões visuais reutilizáveis com animações performáticas, transitions, prefers-reduced-motion e accessibility states

**21. UI Architecture & Component Systems Avançado** *(próprio)*
- 21.1 Projetar bibliotecas de componentes escaláveis com APIs estáveis, composição avançada e contratos semânticos
- 21.2 Implementar componentes headless, compound components, controlled/uncontrolled patterns e polymorphic components
- 21.3 Garantir acessibilidade avançada com focus management, roving tabindex, ARIA patterns e testes automatizados
- 21.4 Estruturar documentação viva com Storybook, visual regression, interaction tests e exemplos executáveis
- 21.5 Gerenciar versionamento, breaking changes, migrações e compatibilidade entre múltiplas aplicações consumidoras
- 21.6 Criar estratégias de theming, design tokens, slots, variants e extensibilidade sem comprometer consistência

**22. Frontend Performance Avançado** *(próprio)*
- 22.1 Definir budgets de performance com Core Web Vitals, métricas customizadas e monitoramento em produção
- 22.2 Otimizar rendering, hydration, bundle splitting, critical CSS, lazy loading e prioridade de recursos
- 22.3 Diagnosticar regressões com RUM, synthetic monitoring, profiling, source maps e análise de traces
- 22.4 Implementar estratégias avançadas de cache, prefetching, prerendering, streaming SSR e edge rendering
- 22.5 Reduzir custo de JavaScript com tree shaking, module federation, partial hydration e islands architecture
- 22.6 Automatizar gates de performance em CI/CD com Lighthouse CI, bundle analysis e alertas de degradação

**23. Design Systems & UX Engineering Avançado** *(próprio)*
- 23.1 Arquitetar design systems multi-produto com governança de tokens, temas, variantes e versionamento
- 23.2 Implementar token pipelines com transformação, distribuição cross-platform e sincronização com ferramentas de design
- 23.3 Construir guidelines técnicas para acessibilidade, responsividade, internacionalização e estados complexos de UI
- 23.4 Desenvolver métricas de adoção, qualidade, consistência visual e cobertura de componentes em escala
- 23.5 Projetar fluxos de contribuição, revisão, release e depreciação para bibliotecas de design system
- 23.6 Integrar experimentação UX com feature flags, analytics, testes A/B e validação de hipóteses de interface

**24. Design de Soluções Front-end Avançado** *(próprio)*
- 24.1 Desenhar arquiteturas frontend alinhadas a requisitos de negócio, domínio, escala, segurança e operação
- 24.2 Definir trade-offs entre SPA, MPA, SSR, SSG, ISR, edge rendering, micro-frontends e arquitetura modular
- 24.3 Projetar integração ponta a ponta com BFF, APIs, autenticação, autorização, observabilidade e contratos
- 24.4 Elaborar roadmaps técnicos para migração, modernização, redução de dívida e evolução incremental
- 24.5 Definir padrões de governança técnica, quality gates, decision records e critérios de adoção tecnológica
- 24.6 Avaliar riscos arquiteturais de performance, disponibilidade, manutenibilidade, custo, segurança e experiência do usuário
